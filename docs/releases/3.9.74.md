# AutoFish 3.9.74 — Self-Contained Dashboard & Live fishserve Fallback

## Summary

- **Dashboard taste pass** (`dashboard.html`):
  - Reworked hierarchy and spacing (brand header, KPI scale, section accents, sticky desktop header, skip link) while keeping every report/API contract and interaction unchanged.
  - Removed the Google Fonts request in favour of a system font stack, so the local dashboard works offline and stays self-contained.
- **Live dashboard override** (`fishserve.js`):
  - `GET /dashboard` resolves `FISHSERVE_DASHBOARD` per request and serves that file when present, so a checkout can follow a live worktree without copying.
  - When the override is missing it falls back to the `dashboard.html` beside `fishserve.js` and labels the response `X-Fishserve-Dashboard: fallback`; healthy responses are byte-identical and labelled `override` (or `local`).
  - The fallback page carries a sticky amber banner naming the missing path, so a stale copy cannot be mistaken for the live dashboard.
- **Release only**: no userscript fishing behavior changed; `dist/autofish.user.js` is rebuilt for the 3.9.74 version stamp.
