# AutoFish 3.9.70 — Non-White Dual-Surface Screen Capture & Card-Only Lightbox

## Summary

- **Dual-Surface Non-White Screen Capture** (`autofish.js`):
  - Added `readCanvasPixels()` and `pickSettledCardSurface()` so trophy capture checks both `uiCanvas` and `gameCanvas` (`app.renderer.canvas`)—capturing from `gameCanvas` whenever `uiCanvas` only paints a white silhouette/mask.
  - Enforces `isCardSettled(r)` inside `captureCardBlob()` so a pure-white silhouette is never saved to IndexedDB.
- **Clean Card-Only Floating Lightbox** (`panel.js`):
  - Removed the synthetic HTML card mock, modal box, header, and `← Prev` / `Save image` / `Next →` buttons.
  - Clicking any trophy item floats only the captured catch card over a dimmed blurred backdrop (click anywhere or press `Esc` to close), falling back cleanly to the official game fish sprite if no screenshot blob exists.
