# AutoFish 3.9.66 — Rare Alerts, Trophy Viewer, Local Dashboard & HUD Polish

## Summary

- **Rare catch Web Audio chime** (`panel.js`, `autofish.js`): Plays an unobtrusive two-note synthesized chime when enabled for Legendary, Secret, Shiny, or Golden catches.
- **24-hour IndexedDB trophy card viewer** (`panel.js`): Stores recent high-tier/variant catch snapshots in `autofish:trophies:v1` IndexedDB for 24 hours, opened from clickable `LEG`, `SEC`, `Trophies`, and `shiny · golden` triggers with full dialog semantics (`Tab`/`Shift+Tab` focus trap, `Escape` close, and two-step clear confirmation).
- **One-click ledger CSV export & update badge** (`panel.js`): Adds **`↓ CSV`** download for the active profile's catch ledger and a 6-hour cached GitHub Releases update indicator on the panel version badge.
- **Local `fishserve` dashboard & `/report`** (`fishserve.js`, `dashboard.html`, `scripts/overnight-report.js`): Adds a live HTML monitoring dashboard at `/dashboard` and JSON summary endpoint `/report`, with automatic `data/runs/` snapshot pruning (14 days / 1,000 files while keeping the last 24h).
- **Oracle & recovery fixes** (`src/loop.js`, `autofish.js`, `session.js`): Prevents false `cast prompt` losses when an active cast prompt is still visible, preserves `row.golden` tracking, and adds bounded (`<=2/h`) `Resume after reload` auto-recovery from `waiting-for-result` game locks while leaving user pauses paused.
- **HUD & dashboard polish** (`panel.js`, `dashboard.html`): Refines hierarchy, keyboard `:focus-visible` outlines, toggle `aria-labelledby`/`aria-pressed` semantics, inline error/syntax banners, and responsive 390px/desktop dashboard layout.
