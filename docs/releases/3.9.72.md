# AutoFish 3.9.72 — Viewport-Flexible Card Detection & Rare Catch Reliability

## Summary

- **Viewport-Flexible `cardBox()` & DPR Scaling** (`autofish.js`, `src/ledger.js`):
  - Replaced the off-center `CARD_BOX_REF` rect with dynamic centered modal sizing (`0.48 * W`, `0.44 * H`) scaled by live canvas height and `canvasDpr()`, fixing the `(335 px, 201 px)` offset measured in fullscreen (`1668×1028`).
  - Scaled `CARD_MIN_*`/`CARD_MAX_*`, `cardShapeOk()` `minW`, and `dialGeoFit()` radius bounds (`DIAL_R_MIN`/`DIAL_R_MAX`) by live `dpr` for HiDPI/zoom resilience.
- **Illustrated Rare-Card Acceptance** (`src/timing.js`, `autofish.js`):
  - Raised `cardShapeOk()` `maxInk` default from `0.30` to `0.46` so darker, richly illustrated Epic and Legendary catch cards (measured live at `0.386–0.391` on `Narwhal` / `Megalodon` / `Fish-Deer`) are no longer rejected as `'inky'`, while narrower `204–216 px` reel panels (`'narrow'`) stay rejected.
- **Guaranteed `fillText` Backstop & `castRetry` Guard** (`src/loop.js`, `autofish.js`, `types.d.ts`):
  - Added `fallbackCatchCard()` during `awaitingCard`: if `F.parseCatch()` holds a complete catch (`species` + `$price`) for `250 ms` while visual `findCatch()` misses, the loop synthesizes centered `cardBox()` coordinates, logs the catch, captures the PNG trophy, and dismisses safely (`via: 'text'`).
  - Prevented `castRetry` from firing `Space` while `F.cardWait`, `F.trophyWaitAt`, or `F.textCardAt` is active so blind retries can never dismiss an unlogged card.
