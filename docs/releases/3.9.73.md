# AutoFish 3.9.73 — Full-Stamp Catch Framing & Phase 2 Impeccable Polish

## Summary

- **Full-Stamp Trophy Framing Fix** (`src/timing.js`, `autofish.js`, `src/loop.js`):
  - Fixed `F.lastCardRect` construction so `cardByShape()` and `cardInBox()` return exact `{ x, y, w, h }` bounds instead of anchoring on the small shape seed (`~35–55 px` upward drift that sliced the bottom postage stamp on `Horseshoe Crab` and `Pike`).

  - Upgraded the floating-card Lightbox with subtle rarity glows, a bottom metadata pill (`Species · Rarity · Weight · Value · Time · N / Total`), `‹` / `›` buttons, `ArrowLeft` / `ArrowRight` keyboard switching, and a full `Tab` focus trap.
- **Dashboard & Install Polish** (`dashboard.html`, `install.html`):
  - Added profile filtering (`All profiles` / per-account) and `Epic+` parity in `dashboard.html`, with `aria-busy` loading states that preserve button focus across refreshes.
  - Updated `install.html` to lead with 1-click zero-server Tampermonkey installation, fixed stale pill placement copy, and unified dark theme tokens.
