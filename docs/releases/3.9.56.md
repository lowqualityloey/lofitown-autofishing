## What changed

3.9.56 is a behavior patch for the inlined userscript. It fixes the catch upload, makes focus
own a seat or hidden pause, and keeps the seat warning from competing with an engaged focus
hold. Nothing about fishing, the planner or the press gate changed.

### Catches use the capture address

The panel started the core with `BASE + '/catch'` whenever `Send catches to CSV` was on. `BASE`
exists for the served panel but is empty in the inlined userscript, so an installed copy fished
normally and never posted its catches. The start path now uses `BASE || captureServer()`, the
same address already used for session rows and overnight capture.

### Focus takes over a seat or hidden pause

A focus hold is now handled before the hidden and seat branches in `tickPaused`. If either guard
has the run paused, focus takes over the pause, clears the seat/hidden timers, and releases a
seat cast hold. A user pause still wins, and the run correctly resumes when focus ends.

### The seat warning yields to focus

The footer's `clock paused — nothing to bite: sit on a chair by the water` warning is now
suppressed while the focus hold is engaged, so it cannot compete with the focus explanation.
With focus off and the character still unseated, the seat warning and cast hold return.

### Rebuilt userscript

The committed `dist/autofish.user.js` was rebuilt for 3.9.56 after the three source fixes.
