## What changed

3.9.52 is a read-only telemetry release. It adds the diagnostics needed to explain a cast-prompt loss and exports the held-first-press counters, without changing fishing behavior or the loss decision.

### Cast-prompt loss diagnostics

- Each cast-prompt loss records `promptChannel` (`box` or `anywhere` - the detector channel, not `CAST!` versus `REEL!`), the glyph verdict, confirmation, prompt coordinates, and whether a catch card was pending.
- `lossDiag` is refreshed on every later prompt sighting while the loss is pending, so confirmation and card state describe the last sighting.
- The diagnostic persists on `__fish.status().lastAttemptLoss`, the `attempt lost` log, and each exported run row.

### First-press telemetry

- The run summary and overnight export carry `firstPressHeld`, `firstPressForced`, and `firstPressHeldForced`.
- Older exports read these as `null`, not fabricated zeros.
