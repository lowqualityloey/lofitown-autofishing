## What changed

3.9.55 fixes the daily budget across midnight. Nothing about fishing, the planner or the press gate
changed.

### A session that crosses midnight spends only the new day

`fishingMs` is the whole session - the duration clock and the session row still need it - so using
it as today's budget charged a 23:30-01:00 run to the new day in full and stopped the cap an hour
early. The reducer now keeps `carriedMs`, the part of the session fished before the current local
midnight, and credits only the post-midnight share against the cap:

- a single tick that spans midnight is split at the boundary;
- a paused run crosses midnight without fishing a frame, and its carry moves with it;
- a stop folds only today's share into `todayMs`, while the session row still reports the whole run.

The panel's `today` meter and the local budget key use the same share, so a reload after midnight
does not resurrect yesterday's minutes.
