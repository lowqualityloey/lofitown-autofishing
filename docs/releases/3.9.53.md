## What changed

3.9.53 breaks the seat-hold deadlock measured live on 2026-11-20: the panel sat at `phase: paused`, `pauseReason: seat`, `needsSeat: true`, `castHold: true` for 60 minutes with no dial. Every Resume re-paused within 0.4-1 s, and the character could not move or fish.

### A parsed catch clears the seat flag

`recordCatch()` now sets `needsSeat = false` when a catch card parses. A catch proves the character was seated; the 45 s watchdog re-latches the flag if the character really is standing.

### A seat hold probes the keybind once a minute

`holdCasts(true)` records `castHoldAt`. While held, the cast-recovery path allows one keybind probe per `seatHoldRetryMs` (60 s), logged as `cast retry` with `seatHold: true`. The probe is the game's own cast keybind: ignored when there is nothing to cast, and a reel when a line is already out. `Math.max(castHoldAt, lastCastTry)` gives the hold a full interval and throttles each later probe; clearing the hold still resets `lastCastTry`, so Resume cannot fire a blind press on the first frame. `seatHoldRetryMs: 0` disables the probe.

### An automatic retry gets the seat grace

A retryable pause (`no-catch`, `cast-stall`, `player-block`, `profile-open`) now sets `seatOverrideUntil = at + 15 s` before it resumes. The seat fact can still be true because a line is already out, not because the character stood up; without the grace the retry's next tick re-paused before its cast could recover. This is the same 15 s window a user Resume already gets.
