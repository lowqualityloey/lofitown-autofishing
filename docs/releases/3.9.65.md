## What changed

3.9.65 ships **Flow** nonstop fishing mode, unified **Local capture**, the **M4 modular core (`src/`)**, dev-only **JSDoc static type-checking (`tsc --noEmit`)**, Flow `resume` limit-bypass fixes, hot-path performance cleanups, and updated live README screenshots.

### Flow Mode & Panel Simplification

- **Added `Mode: Flow | Timed`** ([session.js](../../session.js), [src/loop.js](../../src/loop.js), [panel.js](../../panel.js)): **`Flow`** runs nonstop until manual **Stop** (`maxMinutes: 0`, skips duration, daily cap, clock window, and cooldown — including on `Pause -> Resume` — and hides the 5 timed/budgeted rows while counting elapsed time up), keeping all safety guards (`seat`, `profile-open`, `player-block`, `result-missing`, `core-crash`, `Pause in focus sessions`, `blindWarning`) active.
- **`Stop when hidden: off` (`hiddenStopMs: 0`)**: Steps down to `off` for pause-only background holds that auto-resume on return.
- **Merged `Local capture` & panel cleanup**: Unified `Send catches to CSV` + `Overnight capture` into one `Local capture` toggle (`localCapture` pref with Expand-Contract migration from legacy `postCatches`/`overnight`), kept **Cozier popup** (`hideUpsell`), and retired the obsolete **Fast first press** UI toggle and amber warning (`F.tune({ fastFirstPress })` remains console-accessible).

### Modular Core (`src/`), Type-Checking & Hot-Path Polish

- **Extracted `src/` UMD modules** (`diagnostics.js`, `ledger.js`, `vision.js`, `timing.js`, `loop.js`) sharing `assembleCore()` across `build-userscript.js` and `fishserve.js`, plus multi-frame headless simulator coverage in `tests/simulator.test.js`.
- **Static JSDoc checking (`npm run typecheck`)**: Added `typescript@7.0.2` devDependency, `tsconfig.json` (`checkJs: true`, `strictNullChecks: true`, `noEmit: true`), `types.d.ts`, and CI `typecheck` job.
- **Hot-path cleanup**: Memoized `F.log()` via `createLedger().getEpoch()` + local day, reused `tickOnce()` status in `panel.js` `render()`, replaced `CREAM(PX(...))` in `creamFraction` with direct pixel indexing, reused `dialSamples = new Uint8Array(DIAL_N)` and removed unused `pat` string construction in `F.sample()`, and consolidated `src/diagnostics.js` summary passes.
