AutoFish for lofi.town

Single-file userscript HUD — casts, reels, tracks your 24h rare trophy cards, and saves CSV ledgers right in your browser.

1-Click Userscript Install (No Server Needed)

Install Tampermonkey (or Violentmonkey) once, install the latest AutoFish userscript below, then open https://app.lofi.town. A collapsed AutoFish pill sits in the top-right corner when minimized, and the panel docks cleanly below the top coins bar when expanded.

Install AutoFish Userscript

For a local build, don't open the raw URL directly: Tampermonkey can stop on its generic SCRIPT INSTALLATION page instead of the install prompt. Open Dashboard → Utilities → Import from URL and paste /autofish.user.js, or import dist/autofish.user.js from file. If importing from URL also fails, use the release URL above.

What AutoFish Handles

  1. Flow or Timed modes — fish nonstop until Stop, or use session length, cooldown, clock window, and daily cap schedules.
  2. Safety guards — pauses honestly when you stand up, focus mode starts, or a tab is hidden, with bounded auto-recovery.
  3. Trophy cards & Catch ledger — per-profile 24-hour rare catch PNGs (Epic+, Shiny, Golden) and 1-click CSV export saved locally.

Keep the Game Window Visible

  • AutoFish requests a browser wake lock to keep your screen awake during sessions.
  • If your OS sleeps or you switch away from the tab, lofi.town freezes frame timers until you return.
  • Use a visible desktop window for unattended or overnight fishing.
