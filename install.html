AutoFish

A control panel for the lofi.town fishing bot. No DevTools, no pasting code.

  1. In a terminal, run node fishserve.js and leave it open. (It serves this page, the panel, and the catch log.)
  2. Drag this link to your bookmarks bar:
    🎣 AutoFish
  3. Open https://app.lofi.town and click the bookmark once.
  4. The panel appears in a corner. Press Start when you are ready to fish.

What the panel does

  1. Session length — it stops itself after the time you set. The cooldown that follows is enforced: Start stays disabled until it runs out.
  2. Clock window — optionally only run between two times, including across midnight. A session that starts outside its window waits for it.
  3. Guards — it pauses when the tab is hidden (the game freezes), stops after two minutes hidden, retries when nothing has bitten for ten minutes, and stops itself at the daily cap.

Leaving it alone

  • The panel asks the browser to keep the screen awake while it fishes.
  • If the screen still locks, the game freezes — nothing bites until you come back, and the panel stops the session rather than burning the clock on frozen frames.
  • Keep the game window visible; a hidden tab is a frozen game.

Want to skip the server?

Install Tampermonkey once, then open /autofish.user.js and press Install. From then on a small 🐟 AutoFish chip sits in the bottom-left corner of lofi.town — click it once to start fishing. No terminal, no bookmarklet, and this page only has to exist for that one install.
